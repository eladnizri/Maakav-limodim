# אתר הקבוצה

אתר סטטי בקובץ אחד (`index.html`). אין צורך בהתקנה, בשרת או בכלי בנייה —
פותחים את הקובץ בדפדפן וזה עובד.

## איך מעדכנים תוכן

כל התוכן נמצא בבלוק אחד בתחתית `index.html`, מתחת לשורה:

```
★★★  כל התוכן של האתר נמצא כאן  ★★★
```

שם נמצאים:

| משתנה       | מה זה                                                   |
|-------------|---------------------------------------------------------|
| `TEAM`      | שם הקבוצה, משפט הפתיחה, קישור לאינסטגרם/וואטסאפ, צבעים  |
| `STATS`     | ארבעת המספרים הגדולים בראש העמוד                        |
| `SQUAD`     | רשימת השחקנים — מספר, שם, עמדה, הופעות, שערים, בישולים |
| `LEAGUE`    | טבלת הליגה (הנקודות והדירוג מחושבים אוטומטית)           |
| `PODCASTS`  | פרקי הפודקאסט                                           |
| `GALLERY`   | תמונות הגלריה                                            |
| `IG_POSTS`  | קישורים לפוסטים מאינסטגרם להטמעה                        |

### תמונות
שמים את קובצי התמונות בתיקייה `football/images/` ומפנים אליהם כך:

```js
{ n:10, name:'אלעד ניזרי', pos:'קישור', apps:23, goals:14, assists:15, photo:'images/elad.jpg' }
```

שחקן בלי תמונה יקבל אוטומטית עיגול עם ראשי התיבות שלו.

### צבעי הקבוצה
משנים שתי שורות ב־`TEAM.colors` וכל האתר משנה צבע:

```js
colors: { main:'#00d47e', second:'#ffd23f' }
```

### פרק פודקאסט
בספוטיפיי: שיתוף ← Embed ← מעתיקים את כתובת ה־`src` מתוך ה־`iframe`.
ביוטיוב: `https://www.youtube.com/embed/VIDEO_ID`.
מדביקים בשדה `embed`. פרק עם `embed` ריק מציג "הפרק יעלה בקרוב".

### אינסטגרם
אינסטגרם לא מאפשרת משיכה אוטומטית של הפיד, אבל אפשר להטמיע פוסטים
ציבוריים בודדים. מוסיפים את הקישורים ל־`IG_POSTS`:

```js
const IG_POSTS = [
  'https://www.instagram.com/p/XXXXXXXXXXX/',
  'https://www.instagram.com/p/YYYYYYYYYYY/'
];
```

הפוסטים נטענים ישירות מאינסטגרם, כך שכל עריכה שלהם שם מתעדכנת גם באתר.

## תצוגה מקומית

פשוט פותחים את `football/index.html` בדפדפן, או:

```bash
python3 -m http.server 8000
# ואז http://localhost:8000/football/
```
